# Changelog

All notable changes to Support Agent will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-23

### Added
- Core support engine with autonomous ticket processing
- MiMo V2.5-Pro integration for reasoning and response generation
- Ticket triage system with P0-P3 priority classification
- Real-time sentiment analysis with emotional state detection
- RAG-based knowledge retrieval with vector embeddings
- Multi-channel support: email, live chat, Discord
- Structured logging with JSON output
- YAML-based configuration management
- Support metrics tracking (resolution rate, response time, CSAT)
- CLI interface with process, listen, triage, and metrics commands
- Docker deployment with Redis and PostgreSQL
- Comprehensive test suite
- Web demo dashboard with live analytics visualization
